Generates molecular designs from an official RFD3 input object.

API model id alias-rfdiffusion3

Before you run this

  • Unconditional 40-50 residue design is the validated path. Other input fields are passed through to RFD3 but were not covered by deployment validation.

Results

Results arrive as a single result.zip. The archive may contain several files — reports, scores and more than one structure — so do not assume a single PDB. BioPortal copies the archive to its own storage as soon as the job finishes, which is what makes it available after the service's 48-hour window closes.
