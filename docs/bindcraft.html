BindCraft

Designs binders against a target structure and filters them.

API model id alias-bindcraft

Before you run this

  • Native quality filters can accept fewer designs than you asked for - a finished run is not a quality guarantee.
  • Output is not deterministic; this build does not wire a seed into the CLI.
  • One design runs on one GPU and cannot be split across several, so the target plus the binder must fit in a single card's memory. Trim the target to the part that matters for binding before uploading it.

Results

Examine the reports and accepted-design outputs in the archive.

Results arrive as a single result.zip. The archive may contain several files — reports, scores and more than one structure — so do not assume a single PDB. BioPortal copies the archive to its own storage as soon as the job finishes, which is what makes it available after the service's 48-hour window closes.
